Click Count

Click the target multiple times

There are no preset ×1 / ×2 / ×3 buttons. Click the same target once, twice, three times, or any number of times. The counter reports the actual number of clicks.

3

Delay

Mouse down → wait → mouse up

Delay is measured in milliseconds. It is about mouse interaction timing — not a general replacement for synchronization.

❌ Don't: add just because your application is slow. Investigate the real synchronization problem.
✅ Use: delay when you are intentionally testing mouse timing/behavior.
4

Force

Normal click vs force click

The overlay blocks the target. A normal click should fail because the target cannot receive the click. The force version should still work.

OVERLAY — blocks normal interaction

What should happen?

Normal Click: should NOT reach the target while the overlay is present.
Force Click: should report that the click succeeded by bypassing the normal actionability restriction.
Remove Overlay: normal click should work again because the target is now unobstructed.

Modifiers

Actually hold the modifier and click

These are real browser interactions. Click the target normally and it should NOT succeed. Hold the required key while clicking and the matching action should succeed.

Try: normal click • Shift + Click • Ctrl + Click • Alt + Click
Try it yourself: First click normally. Then hold Shift and click. Repeat with Ctrl and Alt. The page detects the actual key state from your mouse click.

Timeout

Maximum wait for the click action

Use a custom timeout when you intentionally need a different action timeout. Values are milliseconds.

10,000 ms = 10 seconds. The timeout is the maximum time Playwright will wait for the click action to become possible.

Option What it does Demo

Keyboard Actions — All Options

locator.press()

Use the controls to demonstrate normal keys, special keys, shortcuts, and the delay between keydown and keyup.

pressSequentially()

Sends characters one by one. Try the two typing speeds. This is useful when an application reacts to individual key events.

keyboard.down() / keyboard.up()

Demonstrates holding and releasing a key.

keyboard.type()

Types text character by character. Delay controls the time between characters.

keyboard.insertText()

Inserts text directly as input. Modifier keys do not change the text inserted by this method.

Keyboard Options — Complete

API Options / arguments Use
locator.press key, delay Press a key on a specific element
pressSequentially text, delay, timeout, signal Character-by-character typing
keyboard.press key, delay Page-level key press
keyboard.down key Hold a key down
keyboard.up key Release a key
keyboard.type text, delay Type text as keyboard input
keyboard.insertText text Insert text directly
Best practice: use locator.press when a particular element should receive the key. Use page-level keyboard actions when you intentionally need global keyboard control.
Note: noWaitAfter is deprecated and has no useful effect.
